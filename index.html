At first, this was only a simple HTML and CSS activity. I wanted to add a little more personality, so I based the design on something I really like—the Avengers.

I kept the page easy to understand, then added a few effects and made sure it also looks good on a phone. It is simple, but it feels like mine.

Why Avengers?

I like how every hero brings something different to the team. It is a good reminder that small skills can come together to create something better.
